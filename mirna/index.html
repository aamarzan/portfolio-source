miRNA-Affinity Predictor

Predict miRNA binding affinity and the effect of competitor RNAs against one or more targets. Provide sequences (multi-FASTA supported), optionally add 3D structures (PDB/mmCIF), and run a batched deep-learning analysis.

Workflow overview:
  1. You can paste multiple miRNAs (multi-FASTA), multiple targets (multi-FASTA), and zero or more competitors (multi-FASTA).
  2. For each competitor, the tool iterates over all targets; for each target, it evaluates all miRNAs in RAM-safe batches.
  3. Two conditions are scored per miRNA: Baseline (no competitor) and With Competitor (if provided).
  4. Results table shows per-row: miRNA ID, Target ID, Competitor ID (if any), Baseline score, With-competitor score, and Competitive effect = Baseline − With-competitor.
Formatting tips
  • miRNA: multi-FASTA required (each sequence needs a header like >hsa-let-7a-5p). Full header text is preserved in results.
  • Targets & Competitors: multi-FASTA supported (one or many). If left blank for competitors, baseline-only analysis is done.
  • Range-aware IDs: For subregions, reference as Header:Start-End (e.g., TP53_3UTR:90-150). Seed Sites will display both local (slice) and global coordinates.
  • 3D files (PDB/mmCIF): optional and must match their sequence. Use the base FASTA header for filenames (e.g., >TP53_3UTR → TP53_3UTR.pdb) even if results show a slice like TP53_3UTR:90-150.
  • Advanced: optional auto-trim of long miRNAs; optional AA→NT back-translation (if enabled server-side).

About this tool

This tool predicts miRNA binding affinity to RNA targets and estimates competitive effects of optional competitor molecules. It fuses sequence features with optional 3D structure-derived features and evaluates inputs in RAM-safe batches.


How it works

  • Input your miRNA(s) as multi-FASTA. You may also provide one or more targets (multi-FASTA) and zero or more competitors (multi-FASTA).
  • The analysis iterates: competitor1 → all targets → all miRNAs, then competitor2 → all targets → all miRNAs, and so on.
  • Advanced options include auto-trimming long miRNAs to a mature-like window and lossy AA→NT back-translation (where enabled).
  • The backend validates inputs, encodes sequences/structures, and performs model inference to produce affinity scores.

Results interpretation

  • Baseline affinity: predicted binding strength without competitor.
  • With competitor: predicted binding strength considering the provided competitor.
  • Competitive effect: Baseline − With-competitor (higher implies stronger competitive interference).
  • For best results, ensure FASTA headers match any provided 3D filenames exactly:
    • >hsa-let-7a-5p → hsa-let-7a-5p.pdb
    • >TP53_3UTR → TP53_3UTR.cif (even if analysis uses TP53_3UTR:90-150)

    • Notes

    • Predictions are based on training data; experimental validation is recommended.
    • 3D structure files must correspond to sequences; mismatches will be rejected.
    • AA→NT back-translation is lossy and may introduce inaccuracies.
