About this tool

This web tool predicts miRNA binding affinity to RNA targets, with optional competitive effects, using sequence and structural features. It supports multi-FASTA miRNA inputs, single target and competitor inputs, and optional 3D structures (PDB/mmCIF). The model expects nucleotide sequences; amino acid inputs can be back-translated if the server allows it.

What’s new

  • Sorting and color gradient based on baseline predicted affinity (descending)
  • miRNA 3D file uploads support multiple files; filenames must match FASTA IDs
  • Server configuration panel reflects live settings (max miRNAs, mature trimming, AA→NT allowed, auth mode)
  • FASTA formatting tips in Inputs to improve labeling and traceability
  • Friendlier error messages, with clear guidance for AA inputs and 3D mismatches

Usage notes

  • Ensure each miRNA has a FASTA header (e.g., >hsa-let-7a-5p) so results are labeled correctly.
  • Provide exactly one target sequence and at most one competitor sequence.
  • 3D files are validated against sequences; mismatches greater than tolerance will be rejected.
  • If your miRNA is longer than 30nt, mature trimming selects a likely 22nt region unless you disable it.
