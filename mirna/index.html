SeedScope™

About this tool

This tool predicts miRNA binding affinity to RNA targets and estimates competitive effects of optional competitor molecules. It fuses sequence features with optional 3D structure-derived features and evaluates inputs in RAM-safe batches.

How it works

  • Input your miRNA(s) as multi-FASTA. You may also provide one or more targets (multi-FASTA) and zero or more competitors (multi-FASTA).
  • The analysis iterates: competitor1 → all targets → all miRNAs, then competitor2 → all targets → all miRNAs, and so on.
  • Advanced options include auto-trimming long miRNAs to a mature-like window and **lossy AA→NT back-translation** (where enabled).
  • The backend validates inputs, encodes sequences/structures, and performs model inference to produce affinity scores.
Workflow overview:
  1. You can paste multiple miRNAs (multi-FASTA), multiple targets (multi-FASTA), and zero or more competitors (multi-FASTA).
  2. For each competitor, the tool iterates over all targets; for each target, it evaluates all miRNAs.
  3. Two conditions are scored per miRNA: Baseline and With Competitor (if provided).
  4. Seed Sites & Heatmaps use **nucleotides**. If you paste **protein (AA)**, the UI auto-enables AA→NT so seed-level views reflect the converted NT, not AA letters.
Formatting tips
  • miRNA: multi-FASTA required (each sequence needs a header like >hsa-let-7a-5p). Full header text is preserved.
  • Targets & Competitors: multi-FASTA supported. You may paste **RNA/DNA** or **protein** (AA). Protein will be back-translated if enabled.
  • Range-aware IDs: Use Header:Start-End (e.g., TP53_3UTR:90-150). Seed Sites show local and global coordinates.
  • 3D (PDB/mmCIF): optional files or **PDB IDs**. Filenames (or IDs) should match the base FASTA header (e.g., >TP53_3UTR ↔ TP53_3UTR.pdb or PDB ID list).

Results interpretation

  • Baseline affinity: predicted binding strength without competitor.
  • With competitor: predicted binding strength considering the provided competitor.
  • Competitive effect: Baseline − With-competitor (higher implies stronger competitive interference).
